## 重现验证

部署配置及冒烟命令见[运维手册](runbook.zh-CN.md)。示例基础 URL 需在本地替换：

```sh
python3 deploy/scripts/smoke.py --base-url https://library.example.invalid
```

默认冒烟检查读取目录及健康相关端点。登录生命周期检查会留下审计/借阅记录及验收图书，随后归还并归档图书。开启前应配置专用测试身份及受控邮件路由。

每个选用的公网入口分别检查可信 TLS、精确健康响应、静态资源、Cookie/CSRF 和业务行为。DDNS 更新不会修改主机防火墙规则。外部探测目标、探测编号、主机日志和私有部署配置应保留在私有运维记录中。

邮件验收需区分 SMTP 传输成功与应用实际 JavaMail 流程。请使用维护者控制的邮箱验证注册、密码找回及借阅通知。API 健康不代表邮件已投递，详见[生产邮件配置](production-mail.zh-CN.md)。

本公开记录不包含真实主机名、账号、密钥或详细部署时间线。私有配置及备份应在仓库外限制访问。
