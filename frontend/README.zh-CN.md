# 前端

[English](README.md) | 简体中文

栖页 Folio 是包含读者端与管理工作台的 React 单页应用。界面和项目文档均支持简体中文与英文。

## 界面语言

通过读者端页头或后台工具栏的地球按钮切换语言。首次访问跟随浏览器语言，默认回退为简体中文；主动选择保存在本地，刷新后继续使用。切换会保留当前路由、登录会话和表单输入，已有校验消息、系统通知、状态、日期、数字格式和 Ant Design 控件也随之切换。币种仍为人民币。书名、作者、简介、分类及用户内容保留原文。

翻译通过 i18next/react-i18next 集中存放于 `src/locales/` 的通用、读者、认证和管理四个命名空间。新增文案时同步补齐两种语言。测试在原有传输/CSRF 检查外，还验证翻译覆盖、插值参数、英文单复数及缓存 API 消息的语言切换。

## 本地开发

使用与 Vite 兼容、仍受维护的 Node.js 版本（Node 22.12 及以上）。安装锁定的依赖并启动开发服务：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。Vite 将 `/api` 和 `/media` 代理到 `http://localhost:8080`。需单独启动后端；前端读取真实 API，不使用假书目或伪造登录成功状态。如需修改后端地址：

```sh
VITE_API_PROXY=http://127.0.0.1:8080 npm run dev
```

## 构建与验证

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

构建先执行严格 TypeScript 检查，再生成 `dist/`。页面按路由拆分加载，包括管理后台。生产环境通过 Caddy 提供静态资源并同源代理 API，无需常驻 Node.js 应用服务。`npm run preview` 仅预览静态产物，不能替代生产 API 反向代理。

使用 React 19、TypeScript 7、Vite 8、React Router 7、TanStack Query 5、Ant Design 6、i18next 27 和 react-i18next 18，依赖版本由 `package.json` 和 `package-lock.json` 锁定。源码使用 Prettier 排版。

## 页面与行为

- 书目、搜索、分类与可借筛选、分页、推荐和书籍详情。
- 当前借阅、仅本人归还、续借、借阅历史、预约、取消和领取。
- 注册、邮箱验证链接、登录与退出、密码恢复与重置链接、个人资料和修改密码。
- 站内通知、已读状态和演示逾期账单。
- 管理概览、书目编辑与上下架/归档、封面上传、CSV 校验/导入、账号角色与状态、借阅与预约记录、可审计的演示账单减免/结清、审计历史。

无封面时通过本地 CSS 生成文字书封，不依赖第三方图片。上传封面来自后端。页面包含加载、空数据、失败、权限不足和不存在状态；读者页面适配手机，管理表格在窄屏可横向滚动。

请求使用 Session Cookie 和 CSRF 请求头。登录后刷新 CSRF，归属操作不传入读者 ID，写请求不自动重试。前端受保护路由仅负责展示，权限和借阅规则最终仍由后端校验。

## 演示与邮件配置

开发构建可显示合成本地/demo 夹具的操作控件。验收时请使用管理员创建的账号和本地选择的凭据。生产默认隐藏夹具自动填充控件，`VITE_DEMO_MODE=true` 仅用于明确隔离的演示构建。`VITE_*` 会进入公开客户端代码，不可放入私有凭据。

注册后请邮箱持有人查看账号确认邮件，按邮件提示验证邮箱或设置密码。邮件链接使用 `/verify-email?token=…` 和 `/reset-password?token=…`。真实验证和密码恢复依赖后端配置的发信通道。前端构建成功本身不能证明 SMTP、后端端到端流程或 NAS 部署已通过验证，这些由项目交付流程验证。

完整规则与交付标准见[实施计划](../docs/implementation-plan.zh-CN.md)。

服务商参数和真实收件检查见[生产邮件配置](../docs/production-mail.zh-CN.md)。环境专属验收结果保存在私有记录中。

依赖检查：运行依赖未报告漏洞。构建工具的传递依赖 picomatch 有一项[尚无修复版本的 ReDoS 公告](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)，导致完整开发依赖审计报告五个关联的高危条目。Vite 仅在本地/构建阶段使用，NAS 运行镜像只包含 Caddy 和静态资源。
